● 🌀 AKS VM Setup — Industry Standard (Deadpool Edition)

  "Maximum effort, minimum BS."

  ---

  🎯 Step 1: Choose VM Size

  # Why this matters: AKS needs CPU/memory headroom for control plane + node pools.
  # Standard_b2s = 2 vCPU, 4GB RAM (dev/test, cheap date)
  # Standard_D8s_v3 = 8 vCPU, 32GB RAM (prod, the real MVP)
  Use Standard_D4s_v3 or higher for prod → Azure Accelerated Networking needs >= 4 vCPU.

  ---

  🎯 Step 2: Pick the Right Region

  # Why: Latency matters, fam. Pick region close to your users + AKS availability.
  az aks create --location eastus --node-count 3
  Pick region where AKS is GA → check regions list
  (https://azure.microsoft.com/en-us/global-infrastructure/services/?products=kubernetes-service).

  ---

  🎯 Step 3: OS = Linux (Ubuntu 22.04 LTS)

  # Why: Kubernetes eats Linux for breakfast. Windows nodes = pain, support, $$$.
  # LTS = 5 years of patches. AKA "we won't ghost you."

  ---

  🎯 Step 4: Enable System-Assigned Identity

  # Why: AKS needs to talk to Azure resources (LB, disks, DNS).
  # Without identity = "Sorry, can't let you do that, Dave."
  az vm identity assign --name <vm-name> --resource-group <rg>

  ---

  🎯 Step 5: NSG (Network Security Group)

  # Why: Default = open season. Lock down ports like a bouncer.
  az network nsg create --name aks-nsg --resource-group <rg>
  # Allow: 22 (SSH), 443 (API server), 80/443 (ingress)

  ---

  🎯 Step 6: Use Managed Disks (Premium SSD)

  # Why: Standard HDD = your pods timing out like a bad Tinder match.
  az vm create --os-disk-size-gb 128 --storage-sku Premium_LRS

  ---

  🎯 Step 7: Azure CNI Networking (not kubenet for prod)

  # Why: Pods get real IPs = easier networking, NSG rules, service mesh works.
  az aks create --network-plugin azure

  ---

  🎯 Step 8: Enable Monitoring + Backup

  # Why: "I don't always monitor, but when I do..." → Container Insights, Azure Defender.
  az aks enable-addons --addons monitoring

  ---

  🎯 Step 9: RBAC + Azure AD Integration

  # Why: Root access for everyone = chaos. AD integration = SSO + audit logs.
  az aks create --enable-aad --enable-rbac

  ---

  🎯 Step 10: Node Pools > Single Pool

  # Why: One pool to rule them all = single point of failure.
  az aks nodepool add --cluster-name <name> --name userpool \
    --node-count 3 --node-vm-size Standard_DS3_v2

  ---

  🎯 Step 11: Autoscaler ON

  # Why: Traffic spike at 3 AM? Cluster auto-scales. You sleep. Win-win.
  az aks update --enable-cluster-autoscaler \
    --min-count 1 --max-count 5

  ---

  🎯 Step 12: Tags Everywhere

  # Why: Cost tracking + ownership = finance doesn't hunt you down.
  az resource tag --tags Env=Prod Owner=DevOps Team=Platform CostCenter=1234
